Проєкт демонструє побудову сучасного багатосторінкового адаптивного сайту з використанням семантичної верстки HTML5, складних макетів на CSS Grid/Flexbox, фреймворку Bootstrap 5 та інтерактивності на чистому JavaScript (ES6+).

## 📖 Огляд проєкту

Гасло платформи: *«Покращуємо кінокультуру разом. KinoLove — це простір для тих, хто не просто дивиться кіно, а відчуває його.»*

Сайт розроблений для об'єднання української спільноти кіноманів, перегляду каталогів стрічок з розширеною фільтрацією, публікації авторських рецензій, тематичних добірок та взаємодії з користувачами.

---

## 🖥️ Основні сторінки та функціонал

1. **Головна сторінка (`index.html`)**:
   - Hero-секція з візуальним закликом до дії.
   - Медіа-блок з інтегрованими відеоплеєрами: сторонній через `iframe` (YouTube) та локальний HTML5-плеєр `<video>`.
   - Семантична адаптивна таблиця порівняння KinoLove з офіційними VOD-платформами та піратськими ресурсами.
   - Інформаційний блок цілей організації («Спільнота», «Якість», «Розвиток»).

2. **Каталог фільмів (`catalog/index.html`)**:
   - Сайдбар фільтрації фільмів за назвою, жанром, датою виходу (`datetime-local`) та кастомними чекбоксами (оригінальний звук, фільми у прокаті, рейтинг 8+).
   - Вітрина акцентного постера («Фільм місяця»).
   - Адаптивна сітка фільмів на базі CSS Grid з описом, акторським складом та інформацією про режисера.

3. **Тематичні підбірки (`collections/index.html`)**:
   - Вкладки (Tabs) для швидкої навігації між загальним каталогом та підбірками.
   - Картки авторських колекцій («Шедеври неонуару», «Українське поетичне кіно», «Візуальний мінімалізм» тощо) з профілем автора.

4. **Кінорецензії (`reviews/index.html`)**:
   - Комплексна асиметрична сітка рецензій на базі **CSS Grid** (`grid-template-areas` / `reviews-grid`).
   - Рецензії на популярні стрічки (*«Початок»*, *«Темний лицар»*, *«Інтерстеллар»*, *«Хатіко»*, *«Великий Гетсбі»*).
   - Плаваючий інтерактивний віджет зворотного зв'язку (`.feedback-blob`).

5. **Авторизація та реєстрація (`login.html`, `register.html`)**:
   - Форми входу та реєстрації користувача.
   - Валідація полів на рівні HTML5: обов'язковість заповнення (`required`), мінімальна довжина пароля, валідація формату українського номера телефону за допомогою регулярного виразу (`pattern="^\+380\d{9}$"`).

## ⚡ Демонстрація JavaScript

Сторінка `js/index.html` та скрипт `js/main.js` містять практичні реалізації завдань на чистому JS:

### Блок 1: Робота з DOM та таймерами
- **Зміна шрифту**: динамічне зчитування параметрів з форми та зміна тексту та розміру кегля в цільовому блоці.
- **Стрибаючий елемент**: автоматичне переміщення іконки у випадкові координати екрана за допомогою `setInterval()`.
- **Маніпуляція атрибутами**: оновлення стилів параграфів за допомогою методу `.setAttribute()`.
- **Цифровий годинник**: реалізація живого годинника реального часу з форматуванням `hh:mm:ss` (`padStart`).
- **Ефект витирання**: плавне згасання прозорості (fade-out) та відновлення контенту з керуванням через інтервали.

### Блок 2: Форми, обчислення та масиви
- **Кольоровий квадрат**: інтерактивна зміна фонового кольору квадрата при виборі значення у списку `<select>`.
- **Розрахунок переплати за іпотекою**: функція фінансового аннуїтетного розрахунку переплати за кредитом.
- **Сортування колекцій об'єктів**: сортування масиву об'єктів за алфавітом (`localeCompare`) та за числовим параметром (зріст).
- **Захист від перегляду коду**: демонстраційне блокування виклику контекстного меню (`contextmenu`) та комбінацій клавіш `F12`, `Ctrl+Shift+I`, `Ctrl+U`.

### Блок 3: Регулярні вирази та захист вмісту
- **Пошук банківських карток**: автоматичне виявлення номерів карток формату `XXXX-XXXX-XXXX-XXXX` у довільному тексті за допомогою регулярного виразу `/\d{4}-\d{4}-\d{4}-\d{4}/g`.
- **Заборона копіювання**: перехоплення подій виділення (`selectstart`), копіювання (`copy`) та гарячих клавіш (`Ctrl+C`, `Ctrl+A`).

## 🎨 Демонстрація Bootstrap

Сторінка `bootstrap.html` демонструє можливості адаптивної сітки **Bootstrap 5.3.8**:
- Складна 12-колонкова система верстки з брейкпоінтами (`col-6`, `col-sm-6`, `col-md-3`, `col-lg-6`).
- Використання зміщення колонок (`offset-md-1`, `offset-lg-0`).
- Вкладені сітки (nested rows/cols) для блоку статистики та картки «Фільм місяця».
- Адаптивне відображення та приховування блоків за допомогою класів видимості (`d-none`, `d-md-block`).
- Утилітарні класи типографіки, кольорів, відступів та вирівнювання (`d-flex`, `justify-content-around`, `align-items-stretch`).

## 🛠️ Використані технології

- **HTML5**: Семантичні теги (`<main>`, `<header>`, `<nav>`, `<section>`, `<article>`, `<aside>`, `<footer>`), вбудоване аудіо/відео, розширені атрибути форм.
- **CSS3**:
  - CSS Custom Properties (змінні теми для швидкої кастомізації).
  - **Flexbox** (навігація, панелі інструментів, вирівнювання контенту).
  - **CSS Grid Layout** (каталог фільмів, картки підбірок, асиметрична сітка рецензій).
  - Медіа-запити (`@media`) для підтримки мобільних та десктопних роздільностей.
  - Кастомізація елементів форми (чекбокси, випадаючі списки, кнопки).
- **JavaScript (ES6+)**:
  - Модульна структура скриптів (`type="module"`).
  - Робота з DOM API (`querySelector`, `getElementById`, `addEventListener`).
  - Таймери та асинхронні інтервали (`setInterval`, `clearInterval`).
  - Регулярні вирази (RegEx).
  - Функціональні методи масивів (`sort`, `map`, `filter`).
- **Bootstrap 5.3.8**: Grid system, Utilities, Flex-контейнери.

## 🚀 Як запустити проєкт

Для перегляду сайту не потрібне встановлення додаткових серверних залежностей — це статичний фронтенд-проєкт.

### Спосіб 1: Через розширення Live Server (VS Code)
1. Відкрийте папку проєкту в [Visual Studio Code](https://code.visualstudio.com/).
2. Встановіть розширення **Live Server** (від Ritwick Dey).
3. Натисніть правою кнопкою миші на `index.html` і оберіть **«Open with Live Server»**.

### Спосіб 2: Локальний веб-сервер Python
Якщо у вас встановлено Python, відкрийте термінал у кореневій папці проєкту і виконайте:
```bash
# Для Python 3
python -m http.server 8000
```
Після цього відкрийте у браузері адресу `http://localhost:8000`.

### Спосіб 3: Пряме відкриття у браузері
Просто двічі клацніть на файл `index.html` у провіднику файлової системи, щоб відкрити його в улюбленому браузері (Chrome, Firefox, Edge, Safari).
